## Изменения на сайте
1. Где менять текст
Весь контент собран в одном файле — src/app/_data/content.ts. Там лежат отдельные массивы для каждой секции:_



Что меняется	Что в файле
Меню в шапке	NAV
Заголовок и кнопки на первом экране	HERO
Текст и пункты вкладок «О центре»	ABOUT_TABS
Карточки деятельности	ACTIVITIES
Специалисты (имя, специальность, категория, комитет)	DOCTORS
События (даты, названия, описания)	EVENTS
Адрес, телефон, email, соцсети	CONTACTS
Открываете этот файл, находите нужный объект по названию — и правите строки в кавычках. Интерфейс подхватит изменения автоматически.

2. Куда добавлять фото специалистов
Два шага:

Шаг 1 — положить файл в public/. Например: public/doctor-7.webp. Желательно тот же формат и пропорции, что у существующих (4:3, около 800×600 px, формат .webp или .jpg/.png).

Шаг 2 — прописать путь в src/app/_data/content.ts в массиве DOCTORS. Добавить новый объект по образцу:_

ts


{
  name: "Новикова Елена Андреевна",
  specialty: "Гастроэнтеролог",
  category: "Врач высшей категории",
  committee: "Этический совет",
  photo: "/doctor-7.webp",   // ← путь к файлу из шага 1
},
Карточка автоматически появится в сетке секции «Специалисты центра» (сейчас сетка рассчитана на 3 колонки — при 7-м и 8-м враче последняя строка просто будет неполной, ничего дополнительно править не нужно).

Если хотите заменить уже существующее фото — достаточно перезаписать файл под тем же именем (например, public/doctor-1.webp), менять код не потребуется.
